# Public Web Navigasyonu

Masaüstü header ve footer bağlantıları aynı sayfadaki bölümlere yumuşak kaydırma
yapar. Giriş bağlantısı `/login`, randevu çağrıları `/login?mode=guest` akışını
kullanır.

## Responsive davranış

- 1120 piksel ve üzerinde tüm header bağlantıları görünür.
- Daha dar ekranlarda bağlantılar erişilebilir bir menüde toplanır.
- Katalog kartları kullanılabilir genişliğe göre üç, iki veya tek sütuna iner.
- 600 piksel altında bölüm boşlukları azaltılır.
- Native uygulamaya web header/footer veya masaüstü grid uygulanmaz.

Widget testleri 1440, 1366 ve 390 piksel genişliklerinde public içerik, bölüm
navigasyonu ve taşmasız mobil menüyü doğrular.
