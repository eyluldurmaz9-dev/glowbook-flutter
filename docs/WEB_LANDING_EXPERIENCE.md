# Web Açılış Deneyimi

Web platformu artık mobil uygulama karşılama ekranını büyütmek yerine bağımsız,
kaydırılabilir bir tanıtım sayfası gösterir.

Bölümler: Ana Sayfa, Hakkımızda, Hizmetler, Paketler, Randevu Al, İletişim ve
footer. Masaüstünde bölüm bağlantıları görünür; dar web ekranında taşmayı önlemek
için marka ve giriş eylemi korunarak uzun navigasyon gizlenir.

Randevu ve giriş çağrıları mevcut uygulama rotalarını kullanır. Native mobil
karşılama akışı değiştirilmemiştir.
